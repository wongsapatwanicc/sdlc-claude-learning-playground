# kopi-mini

repo ซ้อมมือ AI-native SDLC (playbook ของ Anthropic) ทำระบบสั่งกาแฟเล็กๆ จากศูนย์ ไล่ตาม loop จริง

## เรื่องมันเป็นยังไง

ร้าน Kopi Mini มี 3 สาขา เจ้าของคือพี่หมิว ปัญหาคือช่วงเช้า 7-9 โมงคิวยาว ลูกค้าเดินหนีวันละประมาณ 30 คน
พี่หมิวอยากให้ลูกค้าสั่งล่วงหน้าแล้วมารับได้เลย

คนที่เกี่ยวข้อง (ไม่มีใครเขียนโค้ดเป็น):
- พี่หมิว — เจ้าของ ตัดสินใจเรื่องธุรกิจ (= PO)
- น้องบีม — หัวหน้าบาริสต้า รู้เรื่องหน้าร้านทั้งหมด
- พี่โอ๊ต — ดูเรื่องเงิน

เราเป็น dev คนเดียวของร้าน ใช้ Claude Code ทำ

## กติกา

ไม่เขียนโค้ดถ้ายังไม่มี intent ที่ accepted แล้ว แค่นั้นเลย

ลำดับของงานแต่ละชิ้น:

```
intent/  ->  specs/  ->  plans/  ->  code + test  ->  PR  ->  deploy
  ทำไม        ทำอะไร      ทำยังไง
```

เจอปัญหาหลัง deploy ก็เปิด intent ใหม่ วนไป

## ทำไปถึงไหนแล้ว

- [ ] Loop 1: ลูกค้าดูเมนู + สั่งได้ 1 แก้ว  <- ตอนนี้อยู่ตรงนี้
- [ ] Loop 2: ลูกค้าคืนเงินเองได้ (เรื่องของพี่โอ๊ต)
- [ ] Loop 3: ออเดอร์เบิ้ลตอนเช้า (น้องบีมแจ้งมา)

แต่ละ loop จะได้ลองของใน playbook ไม่เหมือนกัน รายละเอียดดูใน `docs/` (ยังไม่มี เดี๋ยวค่อยเขียน)

## เริ่มยังไง

เปิด Claude Code ใน folder นี้ แล้วให้มันสัมภาษณ์เรา โดยเราเล่นเป็นพี่หมิว

```
ช่วยสัมภาษณ์ผมทีละข้อ เพื่อเขียน intent ตาม intent/_template.md
ผมเป็นเจ้าของร้านกาแฟ อยากให้ลูกค้าสั่งออนไลน์ได้
ถ้าผมตอบเป็น solution ให้ถามกลับว่าปัญหาจริงคืออะไร
อะไรที่ผมไม่รู้ให้ใส่ open questions อย่าเดาเอง
```

ได้ไฟล์ใน `intent/` แล้วอ่านทวนเองก่อน commit (อันนี้สำคัญ Claude เดาเก่ง)

## โน้ต

- ชื่อไฟล์ intent: `YYYY-MM-DD-ชื่องาน.md` เช่น `2026-11-06-online-order.md`
- stack ยังไม่เลือก จะเลือกตอนทำ spec ของ loop 1
- อ้างอิง: Anthropic, *The AI-native SDLC playbook* (2026)
