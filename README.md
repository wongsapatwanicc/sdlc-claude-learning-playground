# ☕ Kopi Mini — SDLC Playground

> Repo นี้ใช้ฝึก **AI-native SDLC** ตาม playbook ของ Anthropic
> ด้วยการสร้างระบบจริงขึ้นมาจากศูนย์ ทีละ loop

---

## 📖 Story

**คุณเพิ่งเข้ามาเป็น developer คนแรกของ "Kopi Mini"**

Kopi Mini เป็นร้านกาแฟเล็กๆ 3 สาขาของ **พี่หมิว** (เจ้าของร้าน)
ทุกวันนี้ลูกค้าต้องมาต่อคิวสั่งที่หน้าร้าน ช่วงเช้า 7–9 โมงคิวยาวจนลูกค้าหลายคนเดินหนี
พี่หมิวนับดูแล้ว วันหนึ่งเสียลูกค้าไปประมาณ 30 คน

พี่หมิวอยากให้ลูกค้า **สั่งล่วงหน้าผ่านออนไลน์** แล้วมารับได้เลยโดยไม่ต้องต่อคิว

ในร้านมีคนที่เกี่ยวข้องอีก 2 คน:
- **น้องบีม** — หัวหน้าบาริสต้า รู้ทุกเรื่องหน้าร้าน (เมนู, เวลาทำ, ปัญหาจริง)
- **พี่โอ๊ต** — ดูแลบัญชีและการเงิน สนใจเรื่องเงินเข้า-ออก และการคืนเงิน

ทั้งสามคน **ไม่ใช่โปรแกรมเมอร์** ไม่รู้จัก git ไม่รู้ว่า API คืออะไร
พวกเขารู้แค่ "ปัญหา" และ "สิ่งที่อยากได้"

คุณมีเครื่องมือคือ **Claude Code** และกติกาของบริษัทคือ
**ทุกงานต้องเริ่มจาก intent ไม่มีใครเขียนโค้ดก่อนตกลงกันว่าทำไปเพื่ออะไร**

---

## 🔁 วิธีทำงานใน repo นี้

ทุกงานจะไหลผ่าน loop เดียวกัน:

```
Plan → Design → Build → Test → Deploy → Maintain
 │        │        │                        │
intent  spec     plan + code                └→ ปัญหาใหม่ = intent ใหม่ (วนกลับ)
```

| ขั้น | ได้อะไร | อยู่ที่ไหน |
|---|---|---|
| Plan | `intent.md` — ทำไม / อยากได้ผลลัพธ์อะไร | `intent/` |
| Design | `spec.md` — ระบบต้องทำอะไร | `specs/` |
| Build | `plan.md` + โค้ด + เทสต์ | `plans/`, `src/` |
| Test / Deploy | PR ที่ผ่านรีวิว + CI เขียว | GitHub |
| Maintain | ปัญหาที่เจอ → intent ใหม่ | `intent/` |

## 🗺️ ภารกิจ (3 loop)

### Loop 1 — "ลูกค้าสั่งกาแฟออนไลน์ได้" 🟢 เริ่มที่นี่
พี่หมิวอยากให้ลูกค้าดูเมนูและสั่งได้ 1 แก้ว แล้วมารับที่ร้าน
> เรียน: Capture intent · Requirements & design · CLAUDE.md · Plan mode · Feedback loop · Hooks · CI/CD

### Loop 2 — "ลูกค้าคืนเงินเองได้" 🔒 ปลดล็อกหลังจบ Loop 1
พี่โอ๊ตเหนื่อยกับการคืนเงินมือทุกวัน
> เรียน: ทำงานกับโค้ดที่มีอยู่แล้ว · Skills · PR review

### Loop 3 — "ระบบเบิ้ลออเดอร์ตอนเช้า" 🔒 ปลดล็อกหลังจบ Loop 2
น้องบีมแจ้งว่าช่วงเช้ามีออเดอร์ซ้ำ ทำกาแฟเกินทุกวัน
> เรียน: Subagents · Evals · Closing the loop

## 🚀 เริ่มต้น

1. เปิด Claude Code ในโฟลเดอร์นี้
2. อ่าน `intent/_template.md`
3. ให้ Claude สัมภาษณ์คุณ โดยคุณสวมบทเป็นพี่หมิว:
   ```
   ช่วยสัมภาษณ์ผมทีละคำถาม เพื่อเขียน intent ตาม intent/_template.md
   ผมคือเจ้าของร้านกาแฟ อยากให้ลูกค้าสั่งกาแฟออนไลน์ได้
   ถ้าผมตอบเป็นวิธีแก้ ให้ถามกลับว่าปัญหาจริงคืออะไร
   เรื่องที่ผมไม่รู้ให้ใส่ Open questions ห้ามเดา
   ```
4. ได้ไฟล์ `intent/YYYY-MM-DD-online-order.md` → commit
5. ✅ จบขั้น Plan ของ Loop 1

## 📏 กติกาของ repo
- ไม่มีโค้ดใดเกิดขึ้นโดยไม่มี intent ที่ `Status: accepted`
- intent ตอบ "ทำไม" — spec ตอบ "อะไร" — plan ตอบ "ทำยังไง"
- ทุก loop ต้องจบด้วยเทสต์ผ่าน + CI เขียว
- เจอปัญหาระหว่างทาง → เขียน intent ใหม่ ห้ามแอบแก้
